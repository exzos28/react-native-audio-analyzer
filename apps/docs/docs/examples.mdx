# Examples

Every waveform on this page is computed from a real recording by the library itself: the C++ core analyzed the audio, and the JS display functions turned the result into SVG paths when this site was built. The recordings are in the public domain ([sources](https://github.com/exzos28/react-native-audio-analyzer/tree/main/apps/docs/examples)).

## Example apps

The repository contains a [bare React Native app](https://github.com/exzos28/react-native-audio-analyzer/tree/main/apps/rn-cli-example) and an [Expo app](https://github.com/exzos28/react-native-audio-analyzer/tree/main/apps/expo-example) with the same demo: a chat bubble drawn with the `chat` preset, and a full waveform with every knob — bar count, metric, scale, reference and zoom — that never decodes again.
