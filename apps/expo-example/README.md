# Expo example (development build)

An Expo SDK app that uses `react-native-audio-analyzer` from this monorepo
(`workspace:*`, resolved from TypeScript sources by Metro). The library has
native code, so it runs in a [development build](https://docs.expo.dev/develop/development-builds/introduction/),
not in Expo Go.

From the repository root:

```sh
yarn && yarn nitrogen
yarn workspace expo-example ios          # or: android — prebuild, build, install
yarn workspace expo-example start        # Metro for the dev client
```

`ios/` and `android/` are generated by `expo prebuild` and are not committed.

`yarn workspace expo-example test` runs the integration test in
`src/__tests__` with `jest-expo`.
